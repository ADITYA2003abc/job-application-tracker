# Job Application Tracker

A simple React-based web application to track and manage job applications in one place.

## Features

- Add new job applications
- Track application status
- View application statistics
- Delete applications
- Responsive and clean user interface
- Basic Express.js backend

## Application Status

- Applied
- Interview
- Selected
- Rejected

## Tech Stack

### Frontend
- React.js
- JavaScript
- HTML
- CSS
- Vite

### Backend
- Node.js
- Express.js
- CORS
